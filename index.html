使用說明

  1. iPhone 連到記錄器的 Wi-Fi。第一次開本頁需要有網路讓離線快取完成（出現「離線可用」）。
  2. Safari 分享 → 加入主畫面，之後像 App 一樣一鍵開，連記錄器沒網路也能用。
  3. 點按鈕會開新分頁顯示記錄器回應；看完用返回或關閉分頁回到控制台。
  4. 看即時影像：先點「① 切換到照片模式」→「② 啟動即時預覽」→ 最上面的大按鈕。
  5. 看完影像要恢復錄影：點「停止預覽」→「切回錄影模式」。
為什麼不能自動顯示連線狀態？
GitHub Pages 是 HTTPS，瀏覽器不允許它用 fetch() 讀 http://192.168.1.254（混內容 + CORS + 私網防護）。 所以改用「點連結開新分頁」—— 這是使用者主動導航，瀏覽器允許， 也不需要任何中繼伺服器。代價是需要看一眼回應、再返回控制台。
照片模式的限制
照片模式下不會錄影。記錄器在錄影模式時改用 RTSP H.264，Safari 不支援， 那種情況一定要額外的轉碼裝置，單靠 iPhone 做不到。
